# EJP Chatroom 部署说明文档

## 1. 运行环境要求

### 1.1 服务器环境

| 项目 | 版本要求 | 说明 |
|------|----------|------|
| 操作系统 | Linux (Ubuntu/Debian/CentOS) | 推荐 Ubuntu 22.04 LTS |
| JDK | 21+ | OpenJDK 或 Oracle JDK |
| MySQL | 8.0+ | 数据库服务 |
| ZFile | 2.0+ | 文件存储服务（可选） |

### 1.2 客户端环境

| 项目 | 版本要求 | 说明 |
|------|----------|------|
| 操作系统 | Windows 10+/Linux/macOS | 支持多平台 |
| JavaFX Runtime | 21+ | 已打包在客户端应用中 |

### 1.3 网络要求

- 服务器需开放 **8888** 端口（WebSocket通信）
- 如需ZFile文件上传，需开放 **8081** 端口（ZFile服务）
- 客户端与服务器需在同一局域网或可通过公网访问

## 2. 数据库搭建

### 2.1 创建数据库用户

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库用户
CREATE USER 'chatroom'@'localhost' IDENTIFIED BY 'chatroom';

# 创建数据库
CREATE DATABASE chatroom_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 授予权限
GRANT ALL PRIVILEGES ON chatroom_db.* TO 'chatroom'@'localhost';
FLUSH PRIVILEGES;

# 退出
EXIT;
```

### 2.2 初始化数据库

```bash
# 执行初始化脚本
mysql -u chatroom -p chatroom_db < server/sql/init.sql

# 输入密码: chatroom
```

初始化脚本包含：
- 用户表（user）
- 用户UUID表（user_uuid）
- 房间表（room）
- 房间成员表（room_member）
- 会话表（conversation）
- 会话成员表（conversation_member）
- 消息表（messages）
- 好友关系表（friendships）
- 好友请求表（friend_requests）
- 用户状态日志表（user_status_log）
- 测试用户（admin/alice/bob，密码均为 123456）
- 示例公共房间（技术交流群、闲聊群）

### 2.3 验证数据库

```bash
mysql -u chatroom -p chatroom_db -e "SELECT username FROM user;"
```

## 3. 配置文件修改

### 3.1 数据库配置

**文件路径**: `server/sql/database.properties`

```properties
# 数据库驱动配置
db.driver=com.mysql.cj.jdbc.Driver

# 数据库连接配置
db.url=jdbc:mysql://localhost:3306/chatroom_db?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=UTF-8&allowPublicKeyRetrieval=true
db.user=chatroom
db.password=chatroom
```

**需要修改的参数**:

| 参数 | 默认值 | 修改说明 |
|------|--------|----------|
| `db.url` | `jdbc:mysql://localhost:3306/chatroom_db` | 如果数据库不在本地，修改主机地址和端口 |
| `db.user` | `chatroom` | 数据库用户名 |
| `db.password` | `chatroom` | 数据库密码，**生产环境务必修改** |

### 3.2 服务配置

**文件路径**: `server/config/service.properties`

```properties
# WebSocket SSL/TLS配置
websocket.ssl.enabled=false
websocket.ssl.keystore.path=path/to/SSl
websocket.ssl.keystore.password=sslpassword
websocket.ssl.keystore.type=type
websocket.ssl.key.password=sslpassword

# ZFile文件服务器配置
zfile.server.url=http://172.31.219.184:8081
zfile.username=chatroom-system
zfile.password=zeXvrDUDacr56Nt
```

**需要修改的参数**:

| 参数 | 默认值 | 修改说明 |
|------|--------|----------|
| `websocket.ssl.enabled` | `false` | 是否启用SSL（生产环境推荐启用） |
| `websocket.ssl.keystore.path` | `path/to/SSl` | SSL证书路径（启用SSL时必填） |
| `websocket.ssl.keystore.password` | `sslpassword` | SSL证书密码（启用SSL时必填） |
| `zfile.server.url` | `http://172.31.219.184:8081` | ZFile服务器地址（文件上传功能） |
| `zfile.username` | `chatroom-system` | ZFile用户名 |
| `zfile.password` | `zeXvrDUDacr56Nt` | ZFile密码，**生产环境务必修改** |

> **注意**: 如果不需要文件上传功能，可以保留默认配置或删除ZFile相关配置。

## 4. 服务器启动步骤

### 4.1 编译项目

```bash
cd /home/jianying/code/ejp/chatroom/server
./compile.sh
```

编译脚本执行以下操作：
1. 删除旧的 `bin` 目录
2. 使用 `javac` 编译所有 Java 文件到 `bin` 目录
3. 复制配置文件到 `bin/server/sql` 和 `bin/server/config`

### 4.2 启动服务器

> **注意**: 编译脚本 (`compile.sh`) 和启动脚本 (`run.sh`) 使用 Linux/Unix 专用的 classpath 分隔符 `:`，仅支持 Linux/Unix 环境。

```bash
cd /home/jianying/code/ejp/chatroom/server

# 确保日志目录存在
mkdir -p log

# 启动服务器
./run.sh
```

启动脚本执行：
```bash
java -cp .:bin:lib/* server.ChatServer 8888 > log/log.txt
```

- 默认监听端口：**8888**
- 日志输出：`log/log.txt`（使用 `>` 覆盖模式，如需追加模式可改为 `>>`）

### 4.3 验证服务器启动

```bash
# 查看日志
tail -f log/log.txt

# 检查端口是否监听
netstat -tlnp | grep 8888

# 测试 WebSocket 连接
curl -i -N -H "Connection: Upgrade" -H "Upgrade: websocket" -H "Host: localhost:8888" -H "Origin: http://localhost:8888" http://localhost:8888
```

### 4.4 后台运行

如需后台运行服务器，可以使用 `nohup` 或 `screen`：

```bash
# 使用 nohup
nohup ./run.sh &

# 使用 screen
screen -S chatroom
./run.sh
# 按 Ctrl+A+D 退出 screen
```

## 5. 局域网访问配置

### 5.1 防火墙配置

**Ubuntu/Debian**:
```bash
# 开放 WebSocket 端口
sudo ufw allow 8888/tcp
sudo ufw reload

# 查看状态
sudo ufw status
```

**CentOS/RHEL**:
```bash
# 开放 WebSocket 端口
sudo firewall-cmd --add-port=8888/tcp --permanent
sudo firewall-cmd --reload

# 查看状态
sudo firewall-cmd --list-ports
```

### 5.2 获取服务器 IP 地址

```bash
# 获取局域网 IP
ip addr show | grep inet | grep -v 127.0.0.1 | awk '{print $2}' | cut -d '/' -f 1

# 或
hostname -I
```

### 5.3 客户端连接

客户端启动后，在登录界面输入服务器地址：

```
ws://<服务器IP>:8888
```

例如：
```
ws://192.168.1.100:8888
```

## 7. 常见问题

### 7.1 数据库连接失败

**问题现象**: 启动服务器时日志显示数据库连接失败

**可能原因**:
1. MySQL 服务未启动
2. 数据库用户名/密码错误
3. 数据库不存在
4. 网络问题（远程数据库）

**解决方法**:
```bash
# 检查 MySQL 服务状态
systemctl status mysql

# 如果未启动，启动服务
systemctl start mysql

# 验证数据库连接
mysql -u chatroom -p chatroom_db

# 检查配置文件
cat server/sql/database.properties
```

### 7.2 端口被占用

**问题现象**: 启动服务器时显示端口 8888 被占用

**解决方法**:
```bash
# 查找占用端口的进程
lsof -i :8888

# 杀死进程（替换 <PID> 为实际进程ID）
kill -9 <PID>

# 或更换端口启动
java -cp .:bin:lib/* server.ChatServer 8889 > log/log.txt
```

### 7.3 权限不足

**问题现象**: 编译或运行时出现 Permission denied

**解决方法**:
```bash
# 赋予脚本执行权限
chmod +x compile.sh run.sh

# 检查目录权限
ls -la
```

### 7.4 ZFile 连接失败

**问题现象**: 上传文件时失败，日志显示 ZFile 连接错误

**可能原因**:
1. ZFile 服务未启动
2. ZFile 地址/用户名/密码错误
3. 防火墙阻止了 8081 端口

**解决方法**:
```bash
# 检查 ZFile 服务状态
curl http://172.31.219.184:8081

# 检查防火墙
sudo ufw status

# 更新配置文件
cat server/config/service.properties
```

### 7.5 客户端无法连接服务器

**问题现象**: 客户端连接超时或连接失败

**可能原因**:
1. 服务器未启动
2. 防火墙未开放端口
3. 服务器地址错误
4. 网络不通

**解决方法**:
```bash
# 在客户端机器上测试连通性
ping <服务器IP>

# 测试端口连通性
telnet <服务器IP> 8888
# 或
nc -zv <服务器IP> 8888

# 检查服务器状态
curl -i http://<服务器IP>:8888
```

### 7.6 SSL 证书问题

**问题现象**: 启用 SSL 后连接失败

**解决方法**:
```bash
# 检查证书文件是否存在
ls -la keystore.jks

# 验证证书
keytool -list -keystore keystore.jks

# 生成自签名证书（开发环境）
keytool -genkey -alias chatroom -keyalg RSA -keystore keystore.jks -validity 3650
```

### 7.7 日志查看

**查看服务日志**:
```bash
tail -f server/log/log.txt
```

**查看错误日志**:
```bash
grep -i error server/log/log.txt
```

## 8. 生产环境建议

### 8.1 安全建议

1. **修改默认密码**:
   - 数据库密码（`database.properties`）
   - ZFile密码（`service.properties`）
   - 测试用户密码

2. **启用 SSL**:
   - 配置有效 SSL 证书
   - 启用 `websocket.ssl.enabled=true`

3. **限制数据库访问**:
   - 生产环境不要使用 `root` 用户
   - 限制数据库用户的访问权限

4. **防火墙规则**:
   - 仅允许必要的端口访问
   - 限制访问来源 IP

### 8.2 性能建议

1. **数据库优化**:
   - 添加适当的索引
   - 定期清理过期数据

2. **日志管理**:
   - 配置日志轮转
   - 定期清理日志文件

3. **监控**:
   - 监控服务器资源使用
   - 设置告警机制

### 8.3 备份建议

1. **定期备份数据库**:
   ```bash
   mysqldump -u chatroom -p chatroom_db > backup_$(date +%Y%m%d).sql
   ```

2. **备份配置文件**:
   - `database.properties`
   - `service.properties`

3. **备份证书文件**:
   - `keystore.jks`
   - `keystore.p12`
